# Offline pack contents

`Nara-Offline-0.1.2-development.zip` is the handoff package to keep outside the Windows disk before a physical test.

- `ISO-OVERLAY/` — optional files copied onto official Windows installation media.
- `NARA/` — plan, install, and local restore commands.
- `RECOVERY/` — independent rollback entry point and diagnostic collector.
- `DOCS/` — physical clean-install and safety instructions.
- `release-manifest.json` — file sizes and SHA-256 values for the staged content.

This pack does not contain Microsoft Windows, activation material, user credentials, OpenAI credentials, drivers, or a boot repair environment.
