NARA RECOVERY PACK - DEVELOPMENT

1. Run COLLECT-DIAGNOSTICS.cmd first when possible.
2. Run RECOVER-NARA.cmd as Administrator to restore the registry snapshot made immediately before Nara applied settings.
3. Recovery never repairs Windows boot, partitions, BitLocker, drivers, or user files.
4. If Windows cannot boot, use official Windows Recovery Environment or the separate stock Windows installer.
5. Keep this folder on external media before reinstalling Windows.
