NARA DEVELOPMENT PACK

START-NARA-AUDIT.cmd hanya membaca perangkat dan menyimpan hasil ke Logs.

INSTALL-NARA-TEST.cmd memasang Phase 1 untuk akun Windows aktif:
- membuat inventaris dan log di C:\ProgramData\Nara
- menyimpan nilai registry asli
- mematikan animasi dan transparansi

RESTORE-NARA-TEST.cmd mengembalikan nilai registry asli.

Phase 1 tidak menghapus aplikasi dan tidak mengubah Defender, Windows Update,
driver, service inti, recovery, atau komponen servicing Windows.
